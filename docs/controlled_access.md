# Controlled Access Notes

The anonymous repository does not include raw public-platform videos. The release plan is:

1. Provide annotation schema, metadata, and derived features where platform terms allow.
2. Provide raw-video access only after a controlled request.
3. Require users to use the data only for research and benchmark evaluation.
4. Prohibit redistribution of raw videos and identifiable account traces.
5. Maintain separate access logs for approved requests.
