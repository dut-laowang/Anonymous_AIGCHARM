# Code Utilities

This folder contains compact, anonymous utilities for the paper release.

- `aigcharm/schema.py`: dataset schema constants and aggregate statistics.
- `aigcharm/metrics.py`: Task A and Task B metric helpers.
- `aigcharm/prompts.py`: VLM prompt templates used by the benchmark.

The full raw-video processing pipeline depends on controlled-access data and external commercial APIs. For review safety, this anonymous repository avoids shipping raw videos, access tokens, server-specific paths, and logs.
